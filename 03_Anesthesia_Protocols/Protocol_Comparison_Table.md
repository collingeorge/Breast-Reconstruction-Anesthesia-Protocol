# Comparing analgesic strategies: an evidence-reading framework

> Independent educational work. Not a clinical protocol, prescription, patient handout, or validated decision aid. This revision is a draft pending clinical and publication review.

| Domain | Questions to ask of each study |
|---|---|
| Population | Augmentation, oncologic surgery, implant revision, or autologous reconstruction? |
| Intervention | Which drugs, blocks, infiltration, and rescue options were actually used? |
| Comparator | Was background multimodal care comparable? |
| Outcomes | Pain, opioid exposure, nausea, respiratory events, hemodynamics, and function? |
| Harms | Were adverse events defined and actively collected? |
| Applicability | Does the evidence apply to the proposed educational population? |

No universal first/second/third-line ordering is supported here. The earlier “lipid emulsion not needed” entries for block-free pathways have been removed: absence of a block does not eliminate local anesthetic toxicity concerns if IV lidocaine or infiltration is used.

No outcome percentages or monitoring durations are asserted without a source-specific extraction.

## Sources and limits

- [Foo et al., 2021: IV lidocaine consensus](https://associationofanaesthetists-publications.onlinelibrary.wiley.com/doi/abs/10.1111/anae.15270).
- [Beloeil et al., 2021: POFA randomized trial](https://pubs.asahq.org/anesthesiology/article-pdf/134/4/541/512443/20210400.0-00011.pdf).
- [Verret et al., 2020: perioperative gabapentinoid meta-analysis](https://pubmed.ncbi.nlm.nih.gov/32667154/).

These sources do not validate an implant-revision-specific regimen. Source-specific populations, comparators, follow-up, and adverse effects must be checked before generalization.
