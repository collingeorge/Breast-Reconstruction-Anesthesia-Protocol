# Breast perioperative learning — reader’s guide

> **Educational work by a pre-medical student — not medical advice.** Not a clinical protocol, prescription, or patient handout, and not for patient care. See [DISCLAIMER](DISCLAIMER.md).

Updated 5 November 2026. This repository has perioperative learning modules with an **educational dosing reference**. Every dose is tagged to a guideline, FDA label or score paper in [DOSING_SOURCES.md](DOSING_SOURCES.md). It also has paired synthetic cases with source and applicability notes. Author: Collin B. George, pre-medical student.

## Read in this order

1. [Start with the paired synthetic cases](APPLIED_CASES.md).
2. Read the [analgesic approaches and comparison](03_Anesthesia_Protocols/README.md), and check any number against [DOSING_SOURCES.md](DOSING_SOURCES.md).
3. [Inspect the supporting review record](PUBLICATION_REVIEW.md) and the [release notes](RELEASE_NOTES.md), which list every dose changed or removed.
4. Read the [authorship and review status](AUTHORSHIP_AND_REVIEW.md), then use the [README](README.md) for the full repository contents.

[Open the paired synthetic cases](APPLIED_CASES.md). The shared anesthesia guide provides additional educational context; it is not an implemented controller capability or an approved patient-care protocol.

## Reading focus

Patient factors, anesthesia options, source-tagged illustrative dosing and reassessment, in an educational format. The doses show what the cited sources state. They are not orders, are not validated for implant revision, and must be individualized by a treating clinician.

## Scope

The repository name retains "Protocol". The material is an educational dosing and workflow reference, **not a clinical protocol**, order set or patient handout. The three analgesic approaches are numbered for reference, not ranked.

Source interpretation, synthetic examples and implemented software behavior have different evidentiary roles. The supporting review record states what was actually checked.
